# Management Review Walkthrough (Executive Path)

Goal: a consistent management review path that is **repeatable** and **role-aware**.

## 1. Portfolio entry

- Page: `/executive-dashboard`
- Check:
  - progress delta vs baseline/compare
  - external readiness counters
  - risk summary + quality summary
  - recent confirmed events (audit trail)

## 2. Version governance

- Page: `/version-governance`
- Check:
  - governance status / release readiness
  - quality gate status
  - external readiness summary (release readiness for consumers)

## 3. Project deep dive

- Page: `/projects` → open `/projects/pm-workbench`
- Check:
  - internal execution summary (progress/risk/cost/version)
  - quality summary (independent from risk)
  - recent confirmed events (who confirmed what)
  - external readiness + mapping (externalProjectId bound or missing)

## 4. External collaboration

- Page: `/data-exchange`
- Demo:
  - import preview/apply to bind externalProjectId
  - export supply readiness bundle (download JSON)
